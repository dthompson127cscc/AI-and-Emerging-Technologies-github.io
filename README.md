# GitHub Learning Portfolio

1. **(a) What emerging technology did you choose? How is AI being used to support this technology?**
The emerging technology I chose is autonomous vehicles (self-driving cars). Artificial Intelligence is used to help these vehicles detect objects, recognize road signs, identify pedestrians, and make driving decisions in real time. AI processes information from cameras, radar, and sensors to safely navigate roads.

2. **(e) Are there any concerns with using AI for this application?**
Yes, there are concerns about safety, privacy, and accountability. AI systems may make mistakes in unusual situations, which could result in accidents. There are also concerns about who is responsible if an autonomous vehicle causes a crash. Additionally, the collection of driving data raises privacy concerns.
